请直接使用服务器管理员提供的地址。通过 Apache 代理访问时，可以使用 https://mirror.example.internal/mirror-control/；不需要改成服务器的 IP。直连 HTTP 不加密令牌，请仅在可信内网使用。

仓库一览

容量来自正式文件账本，不是磁盘实际占用量。磁盘使用率达到 85% 提示空间偏低，达到 95% 提示空间紧张；多个软件源可能位于同一磁盘。

仓库维护任务

本页显示每个软件源最近 20 条维护记录，每 5 秒尝试更新。操作任务时，请进入对应软件源。

状态文件导出任务

导出在服务器上执行，关闭页面不会取消任务。完成后可以再次连接并下载。支持文件保存接口的浏览器将直接写入磁盘；其他浏览器可使用 Windows 客户端下载大型文件。
